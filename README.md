# lucky-page（幸运翻页机）

基于 ESP32-S3 的单机抽奖翻页固件：按下按钮 → 水果机随机减速翻页 → 停在中奖页 → TTL 热敏打印机打出中奖小票。

- 设计文档：`docs/superpowers/specs/2026-09-29-lucky-page-design.md`（决策 D1–D23）
- 实现计划：`docs/superpowers/plans/2026-09-29-lucky-page.md`
- 评审记录：`docs/superpowers/reviews/2026-09-29-review.md`
- 需求：`reqs/req0001_lucky-page.md`

## 硬件

| 功能 | 引脚 | 说明 |
|---|---|---|
| DMX512 翻页机 | UART1: TX=G17, RX=G18, DE=G4 | TTL485 方向控制 |
| TTL 打印机 | UART2: TX=**G9**, RX=**G10**, CTS=**G11** | 打印机侧 TX→G10、RX→G9、CTS→G11；G43/44 是板上 TX0/RX0，禁止占用（D18） |
| 抽奖按钮 | G8 | 高电平有效；长按=打印测试票 |
| 板型 | ESP32-S3-N16R8 | 16MB Flash + 8MB Octal PSRAM |

打印机接线排障（现场命令，免重烧）：
- `ppins` — 逐个脚测电平，判断打印机**是否真的接上了**（悬空 = 没接/没上电）
- `pscan` — 扫描全部安全空闲脚，找出打印机**实际接在哪**
- `pprobe` — 发 ESC/POS 状态查询并回读，判断在线；会识别"悬空脚噪声"避免误判在线
- `pswap` — TX/RX 接反时一键对调（持久化）
- `pflow off|cts|rts|both` — 流控方向：`rts`=ESP32 驱动打印机 CTS（打印方向），`cts`=打印机驱动 ESP32（仅状态回读）

⚠️ 两个方向都叫 "CTS"，接反的表现是「一个字节都不打」；默认关闭流控，避免两个输出端抢一根线。

## 使用

1. 上电后自动归零（约 10.5s，机械释放等待；期间拒绝开奖）
2. WiFi 连接 `lucky-page-XXXX`（密码 `12345678`），浏览器打开 `http://192.168.4.1`
   - 首页：抽奖按钮 + 实时状态
   - 奖池：分级数量/概率/库存配置（默认 30 页 4 级）
   - 小票：**块编辑器**——自由增删/排序内容块（文字行/分隔线/二维码/Logo/走纸），
     每行可设对齐(左中右)、字号(1×/2×)、加粗；点参数即可插入 `{shop}` `{date}` `{time}` `{weekday}` 等 21 个参数；
     保存前实时预览（中奖/未中奖两版），校验不通过会给出具体原因且不保存
   - Logo：上传商家 Logo（浏览器侧二值化）
   - 标定：30 页行程值逐页点动验证（**30 页可用性判据见该页提示**）
3. 按下按钮即抽奖：水果机减速翻页 ≈4.9~5.3s → 落定 → 打印小票

## 关键设计决策（详见设计文档 §12）

| # | 决策 |
|---|---|
| D2 | 先抽奖 → 再翻到该页（票面与机器 100% 一致） |
| D11 | 开机必须归零，完成前禁止开奖 |
| D18 | 打印机 **G9(TX)/G10(RX)/G11(CTS)**；G43/44 禁用 |
| D21 | 行程跨度 + 互异/最小间隔断言 + 30 页可用性判据 |
| D22 | 库存/票号 SaveSync 同步落盘；Settings 字段表驱动 |
| D23 | Web 读走 seqlock 快照，杜绝 UAF |
