## 1. 交付内容

### 1.1 设计系统 `app.css`（v2，唯一来源）
- **语义色分离**：`--brand`（品牌/主操作/当前 tab）、`--ok`、`--warn`、`--danger`（仅破坏性操作）、`--info`；
  表面 `--bg/--surface/--surface-2/--inset` + `--border`；文字三档且对比度达标
  （正文 ≥13:1、次要 ≥6:1、弱化 ≥4.6:1）。
- **骨架组件**：`.page-head`（标题+说明+chip）· `.card-head` · `.kv` · `.metrics` · `.chip` · `.msg` ·
  `#toast` · `.zone-danger` · `.empty` · `.field` · `.prob-bar` · `.seg`。
- **兼容层**：v1 的 `.card/h3/button/.primary/.pri/.mini/.note/.hint/.warn/.ok/.row/.actbar/.sheet/
  .tbl-cards/.psel/pre.preview` 全部保留语义 → 6 页 JS 无需重写。
- **未改的量纲**（校验锁定）：760px · 卡片 16/12 · 按钮 8×16·14·8 · 输入 8×10·14·8 · h3 15px。

### 1.2 `app.js`
- 导航高亮 + `aria-current="page"`；
- 新增 `toast(text,kind)`、`showMsg/hideMsg`（消息条），供各页复用（保存成功不再只靠 12px 小字）。

## 2. 与既有断言的适配（117 项必须全绿）

| 断言 | 处理 |
|---|---|
| 6 页 nav 文案序列一致 / 选中底色一致 | 统一为"品牌 + 6 tab"，高亮仍由 `app.js` 单点判定 |
| artnet 结构（`.status-row`/`.card-title`/通栏 `.action-btn primary`/`h1`） | **类名与结构原样保留**，只换视觉令牌 |
| 状态卡四项 `.status/.it/.k/.v` | 保留类名，仅重绘外观（2×2 手机栅格不变） |
| `.tbl-cards` 手机转卡片 / `td::before` | 保留，概率列新增条形不影响 `data-label` |
| 画布拖动量纲 `colw=14/lineh=22`、右栏、抽屉、底栏 | 未触碰 |
| 设计系统统一（h3 15px 等） | 首轮误改成 14px → **已改回 15px**（设计让步于既有契约） |
| WiFi 文案「长按恢复按钮 5 秒」「不会清掉奖池/模板/标定」 | 首轮改写丢了 `#resetHint` → **恢复 id 并保证关键词** |
| 触控 ≥40px | 工具条 `select` 的紧凑高度**只用于桌面**（`@media(min-width:641px)`） |

## 3. 过程中发现并修掉的问题

1. **`.msg` 用 flex 导致证据文案错列**：WiFi 的 `resetEvidence` 内含多个 `<b>`，
   flex 把每个子元素拉成独立列 → 文字碎成多栏。改为块级（左侧色条仍保留）。
2. **首页状态重复**：页头 chip 与卡内 chip 同时显示"可开奖"→ 卡内改为一行弱化文字（`#state` 仍由 JS 更新）。
3. **Logo 删除无二次确认**（v1 直接 DELETE）→ 增加 `confirm()`，与其余破坏性操作口径一致。
4. **清零全部/重置库存/清除网络** 统一进 `.zone-danger`，文案写明"不会影响什么"。

## 5. 取舍与后续

- **未引入新 JS 框架/构建**：页面仍是单文件 + 共享 CSS/JS，符合"SPIFFS 直接烧"的现场约束。
- **未做亮色主题**：现场是暗环境设备，暗色是刻意选择；若需要可加 `prefers-color-scheme` 分支。
- **导航在手机上不显示品牌**：宽度换 6 个 tab 的可用性（品牌在桌面端显示）。
- **后续可选**：把 `#toast` 用到保存页面的所有成功路径（目前 prizes/logo/index/calibrate 已接）。
