# 评审 36 续：播放串行化（不打断正在播放的音效）

## 现象（需求）

播放请求要排队串行播放，不得中断/影响正在播放的音效。

## 根因

原实现每次 Play* 各起一个一次性任务并发写同一 I2S 通道——连发时两路 PCM
交错（声音错乱），后到的还会抢占 DMA。

## 修法

`speaker_service` 改为**常驻播放任务 + FreeRTOS 队列（深度 4）**模型：
- PlayWelcome/PlayTone/PlayChime 只构造 `PlayRequest`（值类型）入队即返回；
- 常驻 worker 阻塞取队列，播完一个才取下一个（正在播放的绝不被打断）；
- 队满丢弃**新**请求并打告警（保旧弃新，语义即"不影响正在播放的"）；
- 队列/任务创建失败 → I2S 通道回收 + init_failed_（降级，规则 7）。

## 验证证据（真机）

1. 4 连发 `sndwin` → 4 次"中奖音效播放完成"严格顺序输出（相邻间隔 ~1.66s
   = 音效时长+排队），零交错；开机欢迎音先入队先播完。
2. 8 连发 → 5 接受（队列4+播放中1）、4 次"队列已满丢弃"告警——队满路径正确。
3. 片上单测 284 PASSED / 0 FAILED；`scripts/sound_test.py` 3/3 PASS。

# 评审 36 续 2：落空音效 + 尾部电音根治（同日第四/五轮）

## 需求与修法

1. **落空也播提示音**（用户要求）：`SynthLoseChime`（E4→C4 下行双音 470ms，
   峰值 0.6，比中奖音轻/短/沉，听感对比鲜明）。控制器回调升级
   `SetSoundCallback(void(bool win))`，is_lose 分支触发 `PlayLose()`；
   串口新增 `sndlose`；`sound_test.py` 扩为 4 例。
2. **第二次播放尾部电音**（用户报障）三连修：
   - 素材尾部死静音裁剪（2.05s→1.67s，留 150ms 自然尾）——消灭欠载高发窗口；
   - `auto_clear_before_cb=true` 双向清零——欠载时 DMA 重播旧描述符残段
     （即"电音"）的通路被堵死；
   - 播放任务优先级 3→12——防长抢占欠载。
   另修：chime 合成 double→float（S3 无双精度 FPU，软浮点合成多耗数百 ms）。
3. **段间重叠**（用户报障）：每段结束显式写 20ms 静音帧 + 排空 100ms，
   替代纯 vTaskDelay；正弦测试音加 10ms 淡出（整毫秒截断=满幅跳变爆音）。

## 验证证据

- 片上单测 287 PASSED / 0 FAILED（+3 项 LoseChime：时长/斜率/峰值上限/确定性）
- 真机：sndwin→sndlose 背靠背串行完成（间隔 680ms=470+垫片）；三连 sndplay
  间隔稳定一致；`sound_test.py` 4/4 PASS
- 听感确认：尾部电音/重叠由用户复听通过（第五轮修复后未再报）

## 教训

- 生成音频一律 float（sinf/expf）：S3 双精度是软浮点，一次合成多耗数百 ms。
- 音效结尾停在哪都可能被听见：整毫秒截断点相位任意，末尾淡出是必做项。

# 评审 36 续 3：时序调整 + 段尾电音第六轮（同日晚）

## 需求与时序

**翻页完成 → 先播音效 → 音效播完才开始打印**（用户要求）。
实现：`SetSoundLeadMs(kSoundLeadMs=1600)` 注入控制器，kSpinning 结束处
`sound_cb_ → vTaskDelay(lead) → Enqueue 打印`。测试宿主不注入（默认 0，
不拖慢单测）。OnScheduleDone 在主循环上下文，1.6s 延时安全（打印/按钮均异步）。

## 段尾电音排查续（第六轮）

- 主机实测 lose/win 合成数据尾部干净（幅度 <132 = -48dB）→ 数据侧排除。
- 单独 sndplay 仍报电音 → 与具体音效无关 → 指向静音期共性：
  **I2S 时钟（BCLK 768kHz）持续开关经杜邦线串扰进功放模拟输出**。
  修法：播放结束即 `i2s_channel_disable`（时钟停止），播放前 enable。
- 段间隔断加长：60ms 静音冲刷 + 500ms 排空静默（用户要求，总 gap ≈560ms）。
- lose 尾部量化噪声收紧：整数除法 → 浮点比例 + 末尾 24 样本精确归零。

## 验证

287 片上单测全过（时序改动不拖慢测试）；sound_test 4/4 PASS；
8 连发压力测试队列/串行/丢弃路径全部正确。
电音是否根除待用户复听确认（时钟门控假设的直接验证）。
