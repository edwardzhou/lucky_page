# 设计：UI 重设计 v2 ——「设备控制台」

> 依据：`reviews/2026-10-23-ui-review.md`（6 页问题清单 + 既有校验约束）
> 原则：**保留语义与类名（不破坏 69 项校验），重做视觉层级与信息结构**。

## 1. 设计语言

### 1.1 语义色（一个颜色只表达一件事）
| 令牌 | 用途 | 值 |
|---|---|---|
| `--brand` | 品牌与**主操作** | `#ff5a4e`（暖红，只给 primary / 品牌标记 / 选中 tab） |
| `--ok` | 正常/成功 | `#35d07f` |
| `--warn` | 注意/进行中 | `#f5a524` |
| `--danger` | **破坏性操作**（删除/清零/重置） | `#e5484d`（仅 btn.danger、危险区边框） |
| `--info` | 链接/中性信息 | `#7aa2ff` |

表面：`--bg #0e1320` → `--surface #161d2c` → `--inset #0f1626`；`--border rgba(255,255,255,.08)`。
文字：`--tx #e8edf7`（对比 ≥13:1）、`--tx-dim #a7b3c9`（≥6:1）、`--tx-mute #8695ad`（≥4.6:1）。

### 1.2 尺度（沿用校验锁定值）
- 卡片 `16px / radius 12`、按钮 `8×16 · 14 · radius 8`、输入 `8×10 · 14 · radius 8`、页面 760px。
- 间距阶：4 / 8 / 12 / 16 / 24；圆角阶：8（控件）/ 12（卡片）/ 999（chip）。
- 字号阶：display 20·700 / section 14·600（+字距 .02em）/ body 14 / caption 12。

### 1.3 新增骨架组件（纯 CSS，不依赖新 JS）
| 组件 | 结构 | 用途 |
|---|---|---|
| `.page-head` | `h1` + `.sub` + `.chip` | 每页统一页头（wifi 已有 h1，保留其断言） |
| `.card-head` | 标题 + `.card-actions` | 卡片头部；替代裸 `<b>`；保留 `.card-title`（wifi 断言） |
| `.kv` | `.kv-row > .k + .v + .a` | 状态行（由 wifi 的 artnet 结构推广） |
| `.metrics` | `.metric > .n + .l` | 指标条（index 累计/今日、标定四值） |
| `.btn` | `.btn.primary/.danger/.ghost/.sm` | 按钮体系（`button` 与 `.primary/.mini` 保留兼容） |
| `.field` | `label + 控件 + .hint` | 表单行统一 |
| `.msg` | `.msg.ok/.err/.warn` | 消息条（左侧 3px 色条 + 图标位） |
| `#toast` | 固定右下/顶部 | 短暂成功反馈（2.6s） |
| `.zone-danger` | 描边 + 标题 + 说明 | 破坏性操作分组 |
| `.empty` | 居中图标 + 文案 | 空状态 |

### 1.4 导航
`nav` = 左侧品牌（`幸运翻页机` + 小圆点）+ 右侧 6 个 tab；桌面一行，手机**单行横向滚动**
（不再换行占两行）。选中态：`--brand` 背景 + 白字 + `aria-current="page"`（由 app.js 增补）。

## 2. 页面改造要点

| 页面 | 改造 |
|---|---|
| index | 页头（状态 chip）→ 指标条（累计/今日）→ 抽奖区（大按钮 + 结果卡，空态）→ 次操作（ghost） |
| prizes | 页头 + 设置条（总页数/耗尽策略）→ 奖池表（概率加**条形**，删除改按钮）→ 危险区（重置库存）→ 固定保存栏 |
| receipt | 页头 → 工具条分组（元素/视图/模板）→ 画布（保持量纲）→ 右栏/抽屉（分区标题）→ 底栏 |
| logo | 页头 → 上传区（拖放视觉）→ 预览（棋盘格底）→ 参数（阈值/抖动）→ 危险区（删除） |
| calibrate | 页头 + 指标条（当前页/基础/偏移/实际）→ 微调网格（+ 绿 / − 红）→ 翻页区 → 危险区（清零）→ 高级折叠 |
| wifi | 页头（保留 h1）→ 状态卡（kv 行）→ 网络列表（空状态）→ 操作区（通栏）→ 危险区（清除网络） |
