# 中奖音效（自动生成）设计

日期：2026-10-25 · 状态：实施中 · 前置：评审 35（欢迎音链路，I2S/音量/命令族已就绪）

## 需求

抽奖中奖（非"谢谢参与"）时自动播放提示音；音效**程序合成**，不引入素材文件。

## 方案

### 音效形态（win_sound 纯函数合成）

上行琶音"胜利和弦"：C5(523Hz) → E5(659) → G5(784) → C6(1047)，每音 130ms，
尾音 C6 延长 450ms 指数衰减；正弦合成 + 每音符短包络（首尾 2ms 渐变防爆音），
峰值 0.8 满幅。总时长 ≈ 840ms @24kHz（对齐 SPEAKER_SAMPLE_RATE）。

### 结构（规则 5）

```
main/speaker/win_sound.{h,cc}   纯函数 SynthWinChime(sample_rate) → vector<int16_t>
                                （无 ESP-IDF 依赖 → 上 test_apps 单测）
SpeakerService::PlayChime()     播放任务内合成（48KB 级缓冲绝不放栈上，规则 §四-5）
LotteryController               kSpinning 结束（结果揭晓、出票并行）时 !is_lose 触发
串口 sndwin                     真机验证命令
```

- 时机：翻页停定、小票入队的同一时刻（提示音与打印并行，不阻塞状态机）
- 落空（谢谢参与）不播（不打扰）；后续可加低落空音，接口已留
- 音量：沿用 SpeakerService 运行时音量（sndvol 可调，当前 100%）
- 降级（规则 7）：I2S 未就绪/合成失败只打日志，绝不影响抽奖与打印
