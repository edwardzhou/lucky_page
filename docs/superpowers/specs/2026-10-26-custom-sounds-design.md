# 自定义音效（欢迎 / 中奖 / 落空）设计

日期：2026-10-26 · 状态：实施中

## 需求

欢迎音、中奖音效、落空音效支持用户**上传自定义音频**；未上传时使用现有默认
（欢迎音 = 固件内置 WAV；中奖/落空 = 程序合成）。可试听、可删除恢复默认。

## 关键决策

1. **浏览器端转码**：上传任意音频（WAV/MP3/OGG…）由前端 `AudioContext.decodeAudioData`
   解码 → 重采样到 **24kHz / 单声道 / 16bit WAV** → 再上传。
   固件因此**不需要 MP3/OGG 解码器**，只需校验 WAV + 必要时线性重采样。
2. **存储**：media 分区（2.875MB）中图片 48 槽占 2.25MB，尾部剩 **0.625MB**
   用作音效区：3 槽 × 192KiB（24kHz 单声道 16bit ≈ 4.0 秒/槽）。
   槽头 magic `SND1` + role + len + crc + rate；写前擦槽、写后回读校验（D15）。
   不新增分区（16MB 已无连续空间，且测试宿主 NVS 在 0xC00000，避免冲突）。
3. **回落链**：自定义存在且校验通过 → 用自定义；否则用默认，绝不因音效缺失静默。
4. **播放**：SpeakerService 新增 `kCustom` 模式（role），播放任务内从 sound_store
   读入 PSRAM 缓冲再走现有串行队列；仍受段间隔断/音量/时钟门控约束。

## 音频约束（上传即校验，超限直接拒绝并提示）

| 项 | 值 |
|---|---|
| 采样率 | 8000–48000（线性重采样到 24000） |
| 声道 | 1 或 2（取平均转单声道） |
| 位深 | 16bit（8bit 也接受，左移扩展） |
| 时长 | ≤ 4.0 秒（≈190KiB PCM） |
| 大小 | WAV ≤ 400KiB |

## API

| 接口 | 说明 |
|---|---|
| `GET /api/sounds` | `{roles:[{role,name,custom,duration_ms,bytes}]}` |
| `POST /api/sounds?role=welcome|win|lose` | body = WAV 二进制 |
| `DELETE /api/sounds?role=...` | 删除自定义（恢复默认） |
| `GET /api/sounds/raw?role=...` | 取 WAV（前端试听）|
| `POST /api/sounds/play?role=...` | 立即试听（自定义优先，否则默认）|

## UI

新页 `sound.html`（侧栏「音效」）：三个角色卡片 = 当前状态（默认/自定义 + 时长）+
试听 + 选择文件 + 上传 + 删除。上传前在前端解码并校验时长，进度/错误提示。
移动端走侧栏抽屉（底部导航维持 5 项）。

## 验证

- 单测：WAV 解码/重采样边界（8k/16k/44.1k/48k、单双声道、8bit、超长拒绝）；
  sound_store 槽头/CRC 纯逻辑。
- 真机：上传 3 段不同音效 → 试听（串口日志确认 custom 生效）→ 删除恢复默认；
  重启后仍在。
