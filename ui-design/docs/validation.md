## 自动验证

命令：`python3 tools/verify.py`。

- 11 项 JavaScript 语法检查通过，覆盖外部脚本、保留页面的内联脚本，以及单文件预览的外层脚本。

- 27 条模拟协议 / 环境隔离断言通过，覆盖：

  - 可用奖级概率归一化、耗尽奖级退出概率、库存重置。
  - 开奖繁忙保护、翻页到打印再完成、重复轮询不重复计数。

  - WiFi 删除必须提供明确目标，网络名称保存但不回显密码。

模拟断言不等同于对真实固件的契约测试。

## 真机仍需验收

| 范围 | 需要确认 |
| --- | --- |
| 静态文件 | 新 JS 能被设备服务提供，MIME 正确，SPIFFS 分区有足够余量 |
| API 协议 | 目标固件支持原前端使用的全部字段、枚举和 HTTP 方法 |
| 奖池 | 保存连续 level、删行后的真实库存、补货和设备同时开奖时的写入一致性 |
| 开奖 | 设备真实随机、状态切换、归零失败、耗尽策略、打印故障和重试 |
| 小票 | 58 / 80mm 实纸、三种模式、字库、列位、QR 扫码、Logo 背景和打印速度 |
| Logo | 图片二值化、设备尺寸上限、损坏位图处理和真实打印结果 |
| 标定 | 执行器行程、每页落点、偏移边界、基础映射、断电后的持久化 |
| 网络 | 热点更名、密码、静态 IP、DHCP、扫描断连、恢复网络和自动校时 |
| 鉴权与权限 | 输入只提供前端，未审查固件的服务端权限控制 |
| 兼容性 | 旧 WebView、触摸设备、屏幕阅读器和全部手机型号 |

使用现代浏览器能力：fetch、AbortController、dialog、Pointer Events、CSS Grid。若目标产品使用老版本 WebView，需要另补兼容处理。

本次未执行真实打印、真实机械动作、真实网络配置变更；也未引入新的后端功能。
